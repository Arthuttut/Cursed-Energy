Block on Head

Renders a block on the top of the entity's head.

Settings:

Setting Type Description Required Fallback Value
block Block Tag ID of the block/block state definition true /

Examples:

{"type":"palladium:block_on_head","block":{"Name":"minecraft:glass"},"hidden_model_parts":[]}

Compound Render Layer

A compound render layer that can contain multiple render layers.

Settings:

Setting Type Description Required Fallback Value
layers Render Layers The list of render layers this compound render layer contains. true /

Lightning Sparks

Renders lightning sparks around the entity.

Settings:

Setting Type Description Required Fallback Value
amount Integer The amount of sparks to spawn during each occurence. false 5
render_settings Laser Renderer Settings The render settings for the sparks. true /
frequency Float The frequency of the sparks. false 0.5

Examples:

{"type":"palladium:lightning_sparks","frequency":0.2,"amount":10,"render_settings":{"glow":"#0000ff","bloom":2,"size":2.0},"hidden_model_parts":[]}

Default Render Layer

Default render layer that renders a model with a texture.

Settings:

Setting Type Description Required Fallback Value
light_emission Integer The light emission of the model. Must be within 0 - 15 false 0
texture Identifier | Dynamic Texture | Texture Reference The texture to render the model with. true /
model_layer Identifier The model layer to render. false If not present, the model of the parent entity will be used.
render_type "minecraft:entity_translucent" | "minecraft:entity_cutout" The render type to render the model with. false minecraft:entity_translucent

Examples:

{"type":"palladium:render_layer","model_layer":{"wide":"example:wide_model","slim":"example:slim_model"},"texture":{"wide":"example:wide_texture","slim":"example:slim_texture"},"light_emission":5,"hidden_model_parts":[]}

Vibration

Renders a vibration effect on the entity.

Settings:

Setting Type Description Required Fallback Value
intensity Integer The intensity of the vibration. true /
fade_ticks Integer | Time String ("40s", "2m", etc.) The time/ticks it needs for the vibration to fade in/out. true /

Examples:

{"type":"palladium:vibration","intensity":10,"hidden_model_parts":[]}
