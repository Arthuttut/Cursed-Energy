Aim

Allows the player to aim their arms.

Settings:

Setting Type Description Required Fallback Value
arm "none" | "main_arm" | "off_arm" | "right_arm" | "left_arm" | "both" The arm(s) that should point. false MAIN_ARM

Examples:

{"type":"palladium:aim"}

Attribute Modifier

Adds an attribute modifier to the entity while the ability is enabled.

Settings:

Setting Type Description Required Fallback Value
modifier(s) Attribute Modifier (attribute*, amount*, operation*, id) The attribute modifier(s) that will be applied true /

Examples:

{"type":"palladium:attribute_modifier","modifier":{"attribute":"minecraft:armor","amount":1,"operation":"add_value"}}
{"type":"palladium:attribute_modifier","modifiers":[{"attribute":"minecraft:jump_strength","amount":{"type":"palladium:moon_phase"},"operation":"add_multiplied_total"},{"attribute":"minecraft:movement_speed","amount":5,"operation":"add_multiplied_base"}]}

Energy Beam

Shoots an beam in the direction the player is looking at.

Settings:

Setting Type Description Required Fallback Value
beam_renderer Identifier The id of the beam renderer to use true /
damage Float The damage the beam deals to entities false 0.0
cause_fire Boolean If the beam should cause fire on blocks false false
set_on_fire_ticks Integer The amount of ticks the hit entity is set on fire false 0
smelt_blocks Boolean If the beam should smelt hit blocks false false
max_distance Float The maximum distance the beam can travel false 30.0

Examples:

{"type":"palladium:beam","beam_renderer":"example:beam_renderer_id","damage":5.0,"max_distance":25.0,"set_on_fire_ticks":20}

Command

An ability that executes commands.

Settings:

Setting Type Description Required Fallback Value
last_tick_commands string[] The commands that are executed on the last tick of the ability being active. false /
first_tick_commands string[] The commands that are executed upon activating the ability. false /
commands string[] The commands that are executed during each tick of the ability being active. false /

Examples:

{"type":"palladium:command","commands":"say Tick","first_tick_commands":"say First Tick","last_tick_commands":"say Last Tick"}

Fire Aspect

Makes this entity's attacks light targets on fire as if fire aspect was used.

Settings:

Setting Type Description Required Fallback Value
time Integer The amount of time, in ticks, that the victim entity will be set on fire for true /
max_time Integer If "should_stack_time" is true, the victim's burn time (in ticks) will not exceed this value after being hit false 1200
should_stack_time Boolean If true, attacking an entity that's already on fire will add the "time" field to their current burn time instead of setting it false false

Examples:

{"type":"palladium:fire_aspect","time":5,"max_time":5}

Gui Overlay

Renders an image on the screen.

Settings:

Setting Type Description Required Fallback Value
rotate Float The rotation of the texture. false 0.0
texture Texture Reference The texture to render. true /
scale Vector 2D The scale of the texture. false net.minecraft.world.phys.Vec2@a7285d2
texture_height Integer The height of the texture. false 256
alignment "top_left" | "top_center" | "top_right" | "middle_left" | "center" | "middle_right" | "bottom_left" | "bottom_center" | "bottom_right" | "stretch" Determines how the image is aligned on the screen. true /
texture_width Integer The width of the texture. false 256
translate Vector 2D The translation of the texture. false net.minecraft.world.phys.Vec2@3f8b8f65

Examples:

{"type":"palladium:gui_overlay","texture":"minecraft:textures/gui/presets/isles.png","alignment":"top_left"}

Invisibility

Makes the player invisible. Also makes mobs not see the player anymore.

Settings:

Setting Type Description Required Fallback Value
opacity_self Float The opacity at which the player will see themself. If this is being set to something less than 0 it will use the default opacity setting. false 0.2
mob_visibility_modifier Float (>= 0.0) A multiplier for how visible the player is to mobs. 0.0 means completely invisible, 1.0 means normal visibility. false 0.0
opacity Float (>= 0.0) The opacity the player will adapt false 0.0

Examples:

{"type":"palladium:invisibility"}
{"type":"palladium:invisibility","opacity":0.1,"opacity_self":0.5,"mob_visibility_modifier":0.5}

Projectile

Shoots a projectile entity

Settings:

Setting Type Description Required Fallback Value
entity_type Entity Type ID ID of an entity type (must be a projectile). true /
inaccuracy Float (>= 0.0) Inaccurary when shooting the projectile false 0
swinging_arm "none" | "main_arm" | "off_arm" | "right_arm" | "left_arm" | "both" The arm which will swing when the projectile is being shot false MAIN_ARM
entity_data NBT Additional NBT data for the projectile entity. false /
velocity Float (>= 0.0) Velocity with which the projectile is being shot false 1.5
ignore_player_movement Boolean Usually, the current velocity of player will be added to the projectile's velocity. This setting can disable that. false false

Examples:

{"type":"palladium:projectile"}
{"type":"palladium:projectile","entity_type":"minecraft:ender_pearl","inaccuracy":0.2,"velocity":2.0,"swinging_arm":"both","ignore_player_movement":true}
