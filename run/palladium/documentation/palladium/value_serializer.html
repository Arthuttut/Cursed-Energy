Ability Animation Timer Value

Returns the value of the animation timer for the specified ability. Defaults to 0 if no ability or animation timer was found.

Settings:

Setting Type Description Required Fallback Value
modify MoLang MoLang function to modify the value. false /
ability Ability Reference The ability to get the animation timer for. Defined in this syntax: <power_namespace>:<power_name>#<ability_key> true /

Examples:

{"type":"palladium:ability_animation_timer_value","ability":"namespace:example_power#ability_key"}

Conditional Value

Returns a value based on whether a condition is met.

Settings:

Setting Type Description Required Fallback Value
condition Condition | Condition[] The condition to test. true /
on_false (Dynamic) Value The value to return if the condition is not met. true /
on_true (Dynamic) Value The value to return if the condition is met. true /

Examples:

{"type":"palladium:conditional","condition":{"type":"palladium:crouching"},"on_true":"crouching","on_false":"not_crouching"}

Float Data Attachment

Setting Type Description Required Fallback Value
modify MoLang MoLang function to modify the value. false /
attachment Data Attachment ID The ID of the data attachment. true /
fallback Float If the data attachment doesn't exist or is not existent in the entity, this fallback value will be used. false /

Examples:

{"type":"palladium:float_data_attachment","attachment":"example:float_attachment_id"}
{"type":"palladium:float_data_attachment","attachment":"example:float_attachment_id","fallback":4.2,"modify":"this * 2"}

Item Open

Checks if an item was opened.

Settings:

Setting Type Description Required Fallback Value
on_false String The value to return if the result is false. true /
on_true String The value to return if the result is true. true /
slot "mainhand" | "offhand" | "head" | "chest" | "legs" | "feet" | "body" | "curios:head" | "curios:necklace" Slot to check for. If none specified, it will use the slot from the current context (if given). false /

Examples:

{"type":"palladium:item_open","on_true":"opened","on_false":"not_opened"}
{"type":"palladium:item_open","slot":"chest","on_true":"opened","on_false":"not_opened"}
{"type":"palladium:item_open","slot":"curios:head","on_true":"opened","on_false":"not_opened"}
