After Image Trail

Renders copies of the entity behind it.

Settings:

Setting Type Description Required Fallback Value
color Color Defines the color/tint of the after image false #ffffff
opacity Float Starting opacity of the after image false 0.5

Examples:

{"type":"palladium:after_image","color":"#ff0000","opacity":0.2}

Gradient Trail

Renders a colored gradient behind the players.

Settings:

Setting Type Description Required Fallback Value
orientation "horizontal" | "vertical" Defines the orientation in relation to the entity in which the gradient will render false VERTICAL
color Color Defines the color of the gradient false #ffffff
offset Float Defines where the gradient will start in relation to entity hitbox. 0.5 is equal to the center. false 0.5
opacity Float Starting opacity of the gradient false 0.5

Examples:

{"type":"palladium:gradient","color":"#ff0000","opacity":0.7,"orientation":"horizontal","offset":0.2}

Lightning Trail

Renders lightning behind the entity.

Settings:

Setting Type Description Required Fallback Value
amount Integer Defines how many lightnings will follow the player false 10
render_settings Laser Renderer Settings The render settings for the lightning. true /

Examples:

{"type":"palladium:lightning","amount":7,"render_settings":{"glow":"#0000ff","size":2.0}}
