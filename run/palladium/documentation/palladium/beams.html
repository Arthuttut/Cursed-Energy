Laser

Renders a laser beam between two points.

Settings:

Setting Type Description Required Fallback Value
render_settings Laser Renderer Settings The render settings for the laser. true /

Examples:

{"type":"palladium:laser","render_settings":{"glow":"#0000ff","size":2.0}}

Lightning Beam

Renders a fluctuating lightning between two points.

Settings:

Setting Type Description Required Fallback Value
render_settings Laser Renderer Settings The render settings for the lightning. true /
segments Integer The amount of segments the lightning should have. false 5
frequency Integer The frequency of the lightning fluctuation. false 2
spread Float The spread of the lightning fluctuation. It defines how "far" the lightning can spread out from the core false 5.0

Examples:

{"type":"palladium:lightning","render_settings":{"glow":"#0000ff","bloom":2,"size":2.0},"segments":10,"frequency":4,"spread":112.0}

Textured

Renders a beam between two points using a custom texture.

Settings:

Setting Type Description Required Fallback Value
light_emission Integer The light emission of the beam. Must be within 0 - 15 false 0
size Float The size/diameter of the beam. false 1.0
texture Texture Reference The texture to use for the beam. true /
rotation Float The initial rotation of the beam in degrees. false 0.0
rotation_speed Float The rotation speed of the beam. false 0.0
render_type "minecraft:entity_translucent" | "minecraft:entity_cutout" The render type to render the beam with. false minecraft:entity_translucent

Examples:

{"type":"palladium:textured","texture":"namespace:textures/beams/example_beam.png","size":2.0,"rotation":45.0,"rotation_speed":20.0}
