Overview

Palladium

  • Empty
  • Repeating Texture

Empty

Empty background. Renders nothing

Repeating Texture

Repeating a texture so often that it fills the background.

Settings:

Setting Type Description Required Fallback Value
texture Identifier Texture path. true /
width Integer (>= 0) Width of the texture file. false 256
height Integer (>= 0) Height of the texture file. false 256

Sprite

Renders a sprite accordingly to fill the background.

Settings:

Setting Type Description Required Fallback Value
sprite Identifier Sprite ID. true /

Texture

Renders a static texture as a background.

Settings:

Setting Type Description Required Fallback Value
texture Identifier Texture path. true /
width Integer (>= 0) Width of the texture file. false 256
height Integer (>= 0) Height of the texture file. false 256
