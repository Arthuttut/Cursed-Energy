Compound

Fits multiple icons into one

Settings:

Setting Type Description Required Fallback Value
icons Icon definition array Array of icons that will be displayed true /

Examples:

{"type":"palladium:compound","icons":[{"item":{"id":"minecraft:apple"},"type":"palladium:item"},{"sprite":"example:sprite","type":"palladium:sprite"}]}

Experience

Displays an amount of experience points of levels

Settings:

Setting Type Description Required Fallback Value
amount Integer (>= 0) Amount of xp points or levels true /
level Boolean Whether or not this will be displayed as xp points or levels false true

Ingredient

An icon that will display all items of an ingredient by cycling through them

Settings:

Setting Type Description Required Fallback Value
ingredient Ingredient / Item The ingredient (check vanilla recipes for how to define ingredients) true /

Examples:

{"type":"palladium:ingredient","ingredient":["minecraft:apple","minecraft:bread"]}
{"type":"palladium:ingredient","ingredient":"#minecraft:planks"}

Item

Displays an item

Settings:

Setting Type Description Required Fallback Value
item Item / ItemStack The item that will be displayed true /

Examples:

{"type":"palladium:item","item":{"id":"minecraft:apple"}}

Item in Slot

Renders an item that's currently in the slot of the player

Settings:

Setting Type Description Required Fallback Value
slot "mainhand" | "offhand" | "head" | "chest" | "legs" | "feet" | "body" | "curios:head" | "curios:necklace" The slot that will be have its item displayed true /

Examples:

{"type":"palladium:item_in_slot","slot":"chest"}

Sprite

Renders a sprite as an icon (sprites are located under 'textures/gui/sprites/)

Settings:

Setting Type Description Required Fallback Value
sprite Identifier The ID of the sprite that will be rendered true /

Examples:

{"type":"palladium:sprite","sprite":"example:my_cool_icon"}

Textured

Render a texture as an icon

Settings:

Setting Type Description Required Fallback Value
texture Texture Reference Path to the texture, or a dynamic texture ID true /
tint Color A tint that will be given to rendered texture false /

Examples:

{"type":"palladium:texture","texture":"example:textures/icon/my_cool_icon.png"}
{"type":"palladium:texture","texture":"example:textures/icon/my_cool_icon.png","tint":"#ff0000"}
{"type":"palladium:texture","texture":"#example:my_dynamic_texture"}
