Default Flight

Default flying type. If the sprint speed is equal or less than the normal speed, this flight will be levitation-only.

Settings:

Setting Type Description Required Fallback Value
sprint_speed Float The sprinting flight speed. If not set, it will be equal to the normal speed. false /
speed Float The normal flight speed. true /
animation Default Flight Animation Settings The animation settings for this flight type. false /

Examples:

{"type":"palladium:flight","speed":1,"sprint_speed":2,"animation":{"asset_id":"namespace:animation_id","body_stiffness":20.0,"limb_stiffness":12.0}}

Swinging

Allows the entity to swing from anchor points, similar to a grappling hook.

Settings:

Setting Type Description Required Fallback Value
max_anchor_height_type "absolute" | "relative" Determines if the maximum height for anchors are relative to the ground, or a fixed y-level. false RELATIVE
max_anchor_height Integer The maximum height for anchor points. true /
swing_interval Integer | Time String ("40s", "2m", etc.) The time (in ticks) the player must be moving forward before a new anchor point is created. false 40
radius Float | Vector 2D The range of distances from the anchor point that the entity can swing at. It can either be a single, fixed number, or an array of 2 numbers that the player can adjust between while swinging. true /
animation Swinging Animation Settings Settings for the swinging flight animation. false /

Examples:

{"type":"palladium:swinging","max_anchor_height":20,"radius":[5.0,10.0],"swing_interval":60,"animation":{"asset_id":"namespace:animation_id","beam_renderer":{"right_arm":"namespace:beam_right_id","left_arm":"namespace:beam_left_id"},"max_lean":50.0,"body_stiffness":15.0,"limb_stiffness":10.0}}
